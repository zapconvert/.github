### ZapConvert

Private file converter for PDFs, Office documents, images, spreadsheets, audio and video. 38 of its
52 tools run entirely in your browser, so files never leave the device; the rest are processed in
memory and never stored.

<br clear="left">

- **Use it online:** [zapconvert.app](https://zapconvert.app)
- **Self-host it:** [zapconvert/zapconvert](https://github.com/zapconvert/zapconvert) (Docker Compose, Unraid, TrueNAS, CasaOS; amd64 and arm64)
- **Unraid templates:** [zapconvert/unraid-templates](https://github.com/zapconvert/unraid-templates)
